# NX-700 评估基线：产品规格与部署配置

- 发布部门：星云科技解决方案部
- 文档编号：NX-EVAL-PROD-001
- 版本：V1.0
- 生效日期：2025-06-01

本文是 RAG 评估基线资料的一部分。运维操作见《NX-700 评估基线：运维与故障处理》，安全要求见《NX-700 评估基线：仓库安全与应急》。

## 1. 产品型号与能力

NX-700 有 Standard、Lite、Pro 三个型号。Standard 适合常规箱式货物搬运，额定载荷 600 kg；Lite 适合中小仓库，额定载荷 350 kg；Pro 适合重载托盘，额定载荷 1000 kg。Pro 型号的驱动轮和激光雷达是专用件，不能与 Standard 或 Lite 互换。

三种型号的车体外廓尺寸均为 1200 mm × 800 mm。Standard 和 Pro 的最低安全通道宽度为 1.8 m，Lite 的最低安全通道宽度为 1.5 m。部署前必须以现场最窄通道为准，不能用平均通道宽度替代。

## 2. 速度、续航与充电

Standard 的正常运行速度上限为 1.5 m/s，Lite 为 1.2 m/s，Pro 为 1.0 m/s。三种型号在额定载荷、环境温度 20～25°C 且地面平整时，单次充电标称续航分别为 9 小时、11 小时和 7 小时。实际续航会受到载荷、坡度、低温和频繁启停影响。

三种型号使用磷酸铁锂电池。Standard 和 Lite 使用 CS-100 充电桩，Pro 必须使用 CS-200 充电桩。使用非认证充电桩会触发安全风险并失去保修支持。Pro 的完整充电时间约 2.5 小时，Standard 约 2 小时，Lite 约 1.8 小时。

## 3. 传感器与定位

NX-700 使用激光雷达、超声波传感器和二维码地标进行环境感知与定位。二维码地标用于辅助定位，不能替代激光雷达。地图首次发布前，部署人员必须完成二维码地标巡检和 SLAM 建图，并在管理后台确认地图版本为已发布状态。

Standard 和 Lite 使用单线激光雷达；Pro 使用双线激光雷达。Pro 的双线雷达备件不能安装到 Standard 或 Lite。所有型号都必须保持激光雷达窗口无遮挡。

## 4. 部署验收条件

部署验收至少包括：最窄通道宽度、充电桩型号、地图版本、二维码地标完整性、急停与防撞条、载荷上限和网络覆盖。任一项不满足时，项目不能标记为“可生产运行”。

生产环境建议将机器人速度限制为额定上限的 80% 作为首周观察策略；首周无异常后，再依据现场安全评审结果调整。速度限制不改变型号的额定载荷和通道宽度要求。
