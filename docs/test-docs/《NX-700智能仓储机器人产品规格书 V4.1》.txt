文档一：《NX-700智能仓储机器人产品规格书 V4.1》
发布部门： 星云科技产品部
发布日期： 2025年3月10日
文档编号： NX-SPEC-700-041

1. 产品概述
NX-700是星云科技第三代自主移动机器人（AMR），主要应用于电商仓储的货架搬运与订单拣选场景。截至2025年2月，NX-700系列全球累计部署量达12,400台，其中中国区占比58%，欧洲区占比22%，北美区占比15%，其余为亚太其他地区。

2. 核心硬件参数
参数项	NX-700标准版	NX-700 Pro版	NX-700 Lite版
最大载重	500kg	800kg	300kg
空载续航	10小时	12小时	8小时
满载续航	6.5小时	8小时	5小时
最高速度	1.8m/s	2.2m/s	1.5m/s
充电时长（0→80%）	45分钟	40分钟	50分钟
定位精度	±10mm	±5mm	±15mm
激光雷达	单线	双线	单线
注意： Pro版的双线激光雷达是其定位精度达到±5mm的关键，但Pro版的满载续航8小时是在环境温度25°C、地面平整度误差小于3mm的理想条件下测得。实际仓储环境中，若地面有超过5mm的沟槽，Pro版续航会下降约18%。

3. 电池与充电系统
NX-700全系采用磷酸铁锂（LiFePO4）电池，循环寿命为3000次（容量保持率≥80%）。

标准版电池容量：48V / 40Ah

Pro版电池容量：48V / 60Ah

Lite版电池容量：48V / 30Ah

充电桩兼容性： NX-700标准版和Lite版可共用CS-100充电桩；Pro版必须使用CS-200充电桩，原因是Pro版电池管理系统（BMS）采用了主动均衡技术，CS-100无法提供所需的通信握手协议。

4. 导航与避障
NX-700采用SLAM+二维码融合导航。在二维码密集区域（每2米一个），定位精度可提升至±3mm（仅Pro版）。避障系统包括：

前置激光雷达（扫描角度270°）

后置超声波传感器（探测距离0.3-2.5m）

紧急接触式防撞条（触发后立即停机）

避障逻辑优先级： 紧急防撞条 > 激光雷达 > 超声波。当激光雷达与超声波同时检测到障碍物时，系统以激光雷达数据为准。

5. 工作环境要求
温度：-10°C 至 45°C

湿度：5% - 85%（无凝露）

地面承重：≥1000kg/m²

地面摩擦系数：≥0.5

若环境温度超过40°C，NX-700会自动将最高速度限制为1.2m/s，以降低电机发热。
