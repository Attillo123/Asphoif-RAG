# 前端测试控制台

## 目标

提供开发期 React + Vite + TypeScript 控制台，用于验证认证、知识库、文档入库、检索、Chat SSE 和 Trace。

## 页面

- 登录：调用 `POST /api/v1/auth/login`，保存 Bearer Token。
- 工作台：切换知识库，创建知识库，上传 Markdown/TXT，轮询入库任务。
- 检索调试：调用 `POST /api/v1/retrieval/search`，展示 Dense、Sparse、Fused 结果及降级原因。
- Chat：使用 `fetch` 和 `ReadableStream` 解析 `start/citation/delta/end/error` 事件，支持实时输出。
- Trace：展示请求 ID、Trace ID、引用、状态和错误信息；详细 Trace 查询待后端阶段 8 提供接口。

## 开发约定

前端通过 `VITE_API_BASE_URL` 配置后端地址，默认 `http://127.0.0.1:8000`。不修改既有后端接口文档；SSE 事件按 `event:` 与 `data:` 解析，遇到 `end` 或 `error` 结束。

## 验收场景

使用 personal 用户验证资源隔离；使用 admin 用户验证指定知识库检索；上传文档后观察任务状态；检索和 Chat 页面检查引用、降级原因、首 token 体验及 Trace ID。
