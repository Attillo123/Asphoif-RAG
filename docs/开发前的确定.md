用户问题	可能包含PII（姓名、手机号、身份证号）	存储前使用正则或NER模型替换敏感实体，如将“张三”替换为 [USER_NAME]。建议存储脱敏后版本，原始版本只在内存中使用，不落库。

LLM 完整输出	可能包含用户不想被记录的内容	生产 Trace 保存脱敏后的完整答案，最多 10,000 字符，并受访问权限和保留周期控制；原始未脱敏输出不落库。
Trace 日志	上述所有信息的集合	生产环境保存脱敏后的完整答案、检索 ID/分数、耗时和版本信息；完整 Prompt 与原始敏感内容不落库。详细 Debug 日志仅在需要时开启，且写入独立的、访问受限的存储。
